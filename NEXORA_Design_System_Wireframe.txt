1. PROJECT OVERVIEW
==================================================

Project:
NEXORA — AI Automation Studio

Positioning:
AI Automation for modern businesses.

Purpose:
This is the first professional landing-page project for the DevHeshmati portfolio. It is designed to demonstrate the ability to build premium, modern, responsive landing pages for real clients.

The project should feel like a premium technology/AI startup website, combining:
- Minimalism
- Futuristic visual language
- Technical aesthetics
- Strong typography
- High contrast
- Smooth motion
- Generous whitespace
- Professional conversion-focused UX

Visual direction:
Premium + Technical + Minimal + Futuristic + Intelligent + Confident

Design inspiration level:
Modern SaaS / AI startup / premium technology products.
The design must remain original and must not directly copy another website.

==================================================
3.10 ANIMATION SYSTEM
==================================================

Three animation levels:

LEVEL 1 — MICRO INTERACTIONS
Use CSS.

Duration:
150–300ms

Examples:
- Button hover
- Card hover
- Icon movement
- Small transforms


LEVEL 2 — COMPONENT ANIMATIONS
Use GSAP + ScrollTrigger.

Typical animation:
opacity: 0 → 1
y: 30 → 0
duration: 0.7–0.9s

Use staggered entrances for groups of elements.

Typical stagger:
0.1s


LEVEL 3 — SHOWCASE ANIMATIONS
Use GSAP timelines.

Examples:
- Workflow visualization
- SVG path drawing
- Parallax
- Counter animations
- Complex hero animations
- Multi-step visual sequences


Animation principles:
- Motion should support hierarchy and storytelling.
- Avoid unnecessary animation.
- Avoid animating layout-heavy properties when possible.
- Prefer transform and opacity.
- Respect prefers-reduced-motion.
- Reduce animation complexity on mobile.

==================================================
22. PERFORMANCE PRINCIPLES
==================================================

The landing page must be visually impressive without becoming unnecessarily heavy.

Rules:
- Use transform and opacity for most animations.
- Avoid unnecessary layout-triggering animations.
- Lazy-load non-critical assets.
- Optimize images.
- Avoid excessive DOM complexity.
- Avoid unnecessary JavaScript.
- Keep reusable components lightweight.
- Reduce animation complexity on mobile.
- Respect prefers-reduced-motion.
- Keep decorative effects visually subtle.

The final result should look like a real commercial landing page, not a tutorial project.
